# Портфолио Комлева О. В.

Сайт без сборки: обычные файлы, которые отдаёт хостинг.

- `index.html` — сам сайт
- `content/` — данные (проекты, визуализации, контакты). Их меняет админка
- `admin/` — админка Decap CMS, открывается по адресу `сайт/admin`
- `images/uploads/` — сюда админка складывает загруженные картинки

Редактировать сайт может только владелец репозитория OlegK3/portfolio.
